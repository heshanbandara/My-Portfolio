# Animated portfolio for GitHub Pages

A responsive HTML/CSS/JavaScript portfolio with scroll reveal, typing animation, animated gradients, hover effects and reduced-motion support.

## Publish
1. Download and unzip.
2. Replace the files at the root of your `heshanbandara.github.io` repository with `index.html`, `style.css`, and `script.js` (keep any other files you still need).
3. Commit and push to the repository's published branch.
4. In GitHub repository Settings > Pages, verify deployment from the intended branch/root.

## Customize
- Update the introduction in `index.html`.
- Replace the example project cards with real project names, screenshots, and repository URLs.
- Change the contact link to your preferred email or contact platform.
- Adjust colors in the `:root` block of `style.css`.

This is a standalone replacement design, not a patch against your existing files. No external JavaScript libraries required. Google Fonts requires an internet connection.
